# Review checklist

Use on a rendered screen. Answer each with evidence from the screen, not from memory.

## Dashboard
- [ ] What is the one message in three seconds? Is it the right one?
- [ ] Does the first screen say what this product is?
- [ ] Does each key number have a verdict, trend, or reason next to it?
- [ ] Are the top metrics named in the user's language?
- [ ] Is there a conclusion before each major chart?
- [ ] What could be removed without hurting the user? Remove it or move it one click away.
- [ ] Can the user find last week's key figure without menu hunting?
- [ ] Is the emotional state on arrival handled (bad news, good news, nothing yet)?
- [ ] Is generated text labeled as generated?

## Onboarding and empty states
- [ ] Is the first screen ever empty? If yes, add sample data, a template, or a pre-filled step.
- [ ] Can a new user get a real result in under five minutes?
- [ ] Is the first attempt safe and reversible?
- [ ] Is anything asked up front that could be asked later?
- [ ] Is each tour step needed? Could the UI teach it instead?
- [ ] Is help given at the moment of need, with a way to practice?
- [ ] After the first win, is the next step offered, not forced?
- [ ] Are notifications and nudges tied to a user need, not a schedule?
- [ ] Do release notes let the user try the change?

## Verdict
List failures ranked by effect on first-session success. Note anything you could not check (no render, no real data, no analytics).
